# 《联结》—— 本书简介
联结：代码的运转之道
作者：@worldhema

> 一本写给所有人的代码科普书：从一个函数，到一群 AI，看懂软件世界的全部秘密。

---

## 这是一本什么样的书？

市面上的编程书，大多在教你**写代码**——记住语法、背下规则、掌握技巧。读完之后，你脑子里装满了一个个孤立的知识点：变量、循环、函数、类、数据库、网络……却始终不明白：**这些零件，到底是怎么拼成一台真正运转的机器的？**

这本书，反其道而行。

它**不教你写代码**，而是带你看懂一件更根本、也更少被人讲清的事——

> **代码的本质，不是"写出语句"，而是"建立连接"。**
> 程序不是一堆孤立的词语，而是一张**不断放大的网**。
> 节点是零件，**连线才是机器**。

全书只讲一件事：**联结**。从最小的连接（两个函数之间），一层一层往外放大，直到最大的连接（一群 AI 协同工作）。每一章都在回答同一个问题——"**这一层，是靠什么连到下一层的？**"

---

## 它适合谁读？

- **对编程好奇、却被术语劝退的普通人**：本书不要求你会写代码，只要求你愿意跟着思考。它用大量生活比喻（家宴分工、公寓水电、餐厅前厅后厨、公司部门协作……），把最硬核的概念讲得像故事一样好懂。
- **写过一些代码、却始终觉得"零散"的初学者和进阶者**：如果你学了很多知识点，却建立不起"整体感"，这本书会帮你把那些孤立的零件，串成一张完整的、能看懂的网。
- **想理解 AI 时代的所有人**：本书第三卷完整讲透了大模型、提示词、工具调用、RAG、智能体（Agent）、多智能体协作——而且是把它们**放在整个软件演化脉络里**讲的，让你看清 AI 不是凭空出现的魔法，而是几十年连接思想的自然延伸。

---

## 一个贯穿全书的主角：CoinJar

为了让"从小到大"有连续性，全书围绕**同一个应用**展开——一个朴素的记账本，名叫 **CoinJar**。

你会亲眼看着它，从一段简陋的代码，一路成长：

```
序章   一段挤在一起、只会记一笔账、一关就忘的代码
  ↓ 卷一  单机篇
一个结构清晰、有界面、能存盘的【完整单机应用】
  ↓ 卷二  网络篇
一个连上全世界、多人共享、能登录、能付款的【云端 Web 应用】
  ↓ 卷三  智能篇
一个听得懂人话、会自主干活、由一支 AI 团队协同的【智能管家】
```

**从一个函数，到一支 AI 团队。** 这既是 CoinJar 的成长史，也是过去几十年软件演化的缩影。

---

## 全书结构：三卷十九部

**卷一　单机篇**（一台机器内部的连接）
函数↔函数 → 模块↔模块 → 文件↔文件 → 目录↔目录 → 代码↔界面 → 应用↔系统

**卷二　网络篇**（跨越机器的连接）
机器↔机器 → 程序↔程序 → 数据↔云端 → 服务器↔浏览器 → 网页↔界面 → 身份↔权限 → 应用↔外部世界（支付）

**卷三　智能篇**（人与 AI、AI 与世界的连接）
人↔模型 → 应用↔模型 → 模型↔工具 → 模型↔知识 → 智能体↔世界 → AI↔AI

---

## 这本书最特别的地方

**它证明了一件事：这十九部，讲的从来不是十九种互不相干的知识，而是同一种"连接思想"，在不断放大的尺度上一次次重演。**

你会反复地、惊喜地发现：

- AI "调用"工具，骨子里就是第一部"函数调用"的放大；
- 语义检索"按意思找"，骨子里就是第三部"路径寻址"的放大；
- 给 AI 看的"工具描述"，骨子里就是第二部"模块接口"的放大；
- 多智能体的"主管"，骨子里就是第一部那个朴素的"总指挥函数"……

**理解了最小的那个连接（函数调用），你就握住了理解一切更大尺度连接的钥匙。**

---

## 读完之后，你会得到什么？

不是"会写代码"的能力，而是一种更底层的、**看世界的方式**。

从此，当你再打开任何一个 App、任何一个网站、任何一个 AI 助手，你看到的不再是一个神秘的黑箱，而是——**一张你能看懂的、层层嵌套的连接之网。**

而这本书最大的野心是：让你发现"连接"远不止适用于代码。

> 从一个细胞，到一个身体；从一个家庭，到一家公司；从一座城市，到整个社会——
> **一切复杂系统的"复杂"，都不源于零件的数量，而源于连接的方式。**

**"联结"，不只是理解软件的钥匙，更是理解一切复杂系统的钥匙。**

这，就是这本书想送给你的礼物。

## 阅读指南

- **按顺序读**：本书是层层递进的，每一部都建立在前一部之上，强烈建议从序章开始顺序阅读。
- **不必记技术细节**：书中所有真实技术名词（IP、TCP、SQL、RAG、向量……）都"点到为止、不要求记"。你只需抓住每个概念"解决了什么连接问题"。
- **留意"回指前文"**：每当遇到新概念，本书都会告诉你"它在前面对应哪个原型"。这些回指，是理解全书主线的关键，别跳过。
- **附录可随时查阅**：书末附有演进图、术语表、动手指南和"思想放大对照表"，可作为通读时的辅助和读后的复习。

## 从源码重新构建

依赖本机的两个转换技能：`md-to-html`（网页版）、`md2book`（PDF，需 playwright chromium）。

```bash
# 1) 生成中间稿
python3 scripts/build_combined.py --mode html     # → build/for_html.md
python3 scripts/build_combined.py --mode pdf      # → build/for_pdf.md

# 2) 渲染成品到 release/
python3 ~/.claude/skills/md-to-html/scripts/md_to_html.py \
    build/for_html.md -o release/the-connection.html -t "《联结》 · The Connection"
python3 scripts/build_combined.py --linkify-html release/the-connection.html
node ~/.claude/skills/md2book/scripts/md2book.js \
    build/for_pdf.md --theme minimal --output release/the-connection.pdf
```
