## 四、卷三规划（框架已立，待写）—— AI 时代

> CoinJar 已是连上整个世界的云端应用，但它只会"按指令办事"。
> 卷三让它长出一个**会聊天、会自动记账、会帮你分析消费的 AI 助手**。

| 部 | 暂定主题 | 联结的尺度 |
|----|---------|-----------|
| 第十四部 | 人与模型 | 自然语言成为新"调用方式"：从点按钮到说人话 |
| 第十五部 | 应用与模型 | 程序如何调用一个 AI 模型（模型 API、提示词） |
| 第十六部 | 模型与工具 | AI 反过来调用你的函数（工具调用 / function calling） |
| 第十七部 | 模型与知识 | 让 AI 连上你的私有数据（检索增强、向量/语义连接） |
| 第十八部 | 智能体与世界 | Agent：会规划、自主调用多工具完成任务 |
| 第十九部 | AI 与 AI | 多智能体协作（编排、协议） |
| 终章 | 联结，是一切的钥匙 | 回望：从一个函数，到人机协同的智能网络 |

**卷三连接暗线**：
- 模型 API 调用 = 系统调用/网络请求的放大（向"一个 AI 大脑"提要求）
- 提示词/工具描述 = 接口/协议的放大（用**自然语言**作约定）
- 语义检索/向量 = 路径/IP 寻址的放大（从"精确地址"到"按含义匹配"）
- Agent 自主循环 = 回调的放大（程序自己决定下一步喊谁）
- 多智能体编排 = 函数调用/客户端服务器的放大（从函数间、机器间，到 AI 间）
